Videha Thesaurus offline app

Open index.html in a browser. The app uses local JavaScript data shards, so no server is required.

Included data
- Videha English-Maithili and Maithili-English thesaurus entries
- Searchable WordNet 2.1 English reference entries
- Raw WordNet 2.1 database and license files in data/wordnet21

Sources and citation
Videha English-Maithili and Maithili-English thesaurus data are presented with English lexical reference from WordNet.

WordNet citation:
Princeton University. "About WordNet." WordNet. Princeton University, 2010.
Citation guidance: https://wordnet.princeton.edu/citing-wordnet
